## 岗位要求

工作职责:
1、问题识别与分析：通过数据分析、用户反馈及日常巡检，识别版权、侵权、引流等问题域中的治理覆盖盲区与异常案例，输出问题归因分析； 
2、策略制定与落地：协助搭建和维护问题域治理规则，参与治理策略（关键词、账号维度、多因子组合等）的设计、评审与迭代； 
3、样本标注与评估：负责治理策略相关的案例标注、效果回评，跟进召回率与准确率变化，反推策略漏放与误伤问题； 
4、数据监控与复盘：跟踪核心治理指标，定期产出策略效果周报/复盘，推动问题闭环； 
5、跨部门协作：与法务、产品、研发、审核等部门协同，跟进专项治理项目的推进与落地。
工作要求:
1、2028 届或 2029 届在校生，本科及以上，专业不限；法学、新闻传播、计算机、统计学等相关专业加分； 
2、对社区内容生态有兴趣和敏感度，B 站深度用户优先，了解版权、引流等社区违规形态者优先； 
3、逻辑清晰、善于归纳总结，能从复杂案例中提炼共性特征并形成规则语言； 
4、认真细致、有耐心，能高质量完成大批量案例的标注与核查工作； 
5、加分项：熟练使用 Excel / SQL / Python 进行基础数据分析；有治理和风控相关实习经历。

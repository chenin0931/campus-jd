## 岗位要求

1、本科及以上在读，专业不限，人工智能相关专业优先。
2、具备 AI 应用实践基础，理解模型请求、Prompt 和工具调用，了解 Harness 中的上下文管理、状态管理与执行机制。
3、对 AI 技术及 B 端应用有热情，学习主动、勤于思考，愿意持续关注模型演进与行业发展。
4、逻辑清晰，具备良好的沟通协调能力、责任心与执行力，能够主动推进任务落地。
5、工作细致耐心，具备用户同理心，能够从用户视角识别产品体验问题并提出可行建议。
6、每周可实习 4 天及以上，持续实习 3 个月以上。
加分项：
有 Agent 搭建经验，熟练使用 Codex、Claude Code 等工具辅助开发、调试与优化。
了解 Agent 在呼叫场景中的技术与体验难点，如实时响应、打断处理、多轮状态管理、工具调用和异常兜底。
有产品设计、效果评测或真实业务项目经验，可提供相关作品。

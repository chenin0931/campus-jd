## 岗位要求

工作职责
1.生态治理建设：参与主客观内容标签的体系建设、质量评估，协助定位内容质量或用户行为问题，参与策略制定与效果追踪；
2.AI 工具落地与运营提效：在内容运营、创作者运营、活动运营等场景中，协助 AI Agent / AI 助理的能力落地，包括工作流梳理、Prompt 调试、效果评估与迭代；
3.数据支持与效果分析：通过 SQL / 数据分析工具，对内容质量、运营效果、策略表现等数据进行提取与分析，输出分析报告，支撑产品与运营决策；
4.跨团队协同：配合算法、运营、研发等团队推进项目落地。
任职要求
1.在校生优先，本科及以上，计算机、信息管理、新闻传播、社会学等相关专业背景；
2.内容感知能力强，有使用内容社区产品的习惯，对内容质量和社区生态有基本判断；
3.对 AI 工具感兴趣，有 Prompt 设计、AI Agent 使用经验者优先，主动学习意愿强；
4.数据基础：有一定的数据分析能力，熟悉 SQL基础者优先；
5.逻辑清晰、结构化表达：能独立整理需求文档、分析报告，表达简洁有条理；
6.有互联网产品、运营或用户研究相关实习经验者优先。

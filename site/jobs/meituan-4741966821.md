## 岗位要求

1. 本科及以上在读，计算机、软件工程、人工智能、数学、统计学等相关专业优先；每周可实习不少于 4 天，持续不少于 3 个月，能够连续实习 6 个月者优先。

2. 熟悉 Python、Go、Java、TypeScript/JavaScript 中至少一门编程语言，具备基本的 Linux、Git 和数据处理能力。

3. 有独立完成技术项目的经历。课程大作业、科研项目、开源项目、比赛作品或个人项目均可，我们更关注你实际解决过什么问题，以及能否交付可运行、可验证的结果。

4. 实际使用过 LLM API 或 AI Coding 工具，如 Codex、Cursor、Claude Code 等；不止停留在聊天体验，曾使用它们完成程序、Agent、自动化流程或其他真实任务。

5. 理解大语言模型的基本原理和能力边界，熟悉 Prompt、上下文管理、Agent、Tool Calling、幻觉等基本概念。


加分项：

1. 对模型和 Agent 评测有强烈兴趣，研究、复现或深度分析过 SWE-bench、Terminal-Bench、ORCA-bench、SREGym、BFCL 等公开 Benchmark。

2. 做过 LLM 应用评测、自动评分器、LLM-as-a-Judge、人工标注质量分析、A/B 实验或统计显著性分析。

3. 熟悉 Docker、CI/CD、可观测性、云原生技术或 SRE/运维场景，对真实软件系统如何开发、运行和发生故障有一定理解。

4. 有高质量开源贡献、编程竞赛、科研论文或技术文章；能够通过作品证明自己的工程能力、研究能力或技术判断力。

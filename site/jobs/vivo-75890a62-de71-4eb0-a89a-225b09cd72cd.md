## 岗位要求

岗位职责：
在这里，您将与我们一起专注于：
1.  参与 vivo 生态产品系统 ID 的设计策略及风格定调；
2.  与产品、用研、架构、可制造、人因、等团队合作，将复杂的营销和产品需求转化为引人注目的设计解决方案；
3.  参与协调不同品类产品的外观关联性，强化品牌统一性，确保系列产品外观协调且可迭代；
4.  参与设计强相关的技术、材料、工艺持续创新；
5.  探索创新方法、研究用户人群、挖掘前沿趋势、沉淀设计方法论，研究目标消费群的潜在需求。

任职要求：
1.  本科及以上学历，设计类、美术类、理工类相关专业；
2.  熟练运用设计行业的创新工具和创新方法，熟悉工业设计的表面处理工艺并能灵活运用； 
3.  精通设计工具，例如 Creo / Rhino / grasshopper / C4D / KeyShot / Adobe Creative Suite 等；
4.  热爱设计，喜欢挑战，有较强的设计创新意识以及对设计追根溯源的猎奇心，不受既有经验和惯性的束缚，积极寻找和引进新的思维、方法、工具；

## 岗位要求

1、2027 届应届毕业生（2026 届优秀毕业生亦可），本科及以上学历。
2、专业不限，以下相关方向优先：计算机 / 自动化 / 机器人工程 / 电子信息 / 工业工程 / 数据科学，或市场营销 / 工商管理 / 信息管理等复合背景。
3、强学习能力与技术理解力：愿意钻研并读懂 SDK/API/PRD 等技术文档，能与研发同学有效沟通（不要求会写代码，但要不怕技术）。
4、良好的沟通协同与推进意识：能在多方之间跟进事项、推动落地，做事有条理、responsive。
5、结构化表达能力：PPT / 文档写作扎实，逻辑清晰，敢于在公开场合表达。
6、对数据敏感：具备基础数据分析意识，会用 Excel，了解或愿意学习 SQL / BI 工具。
7、特质：目标感强、皮实抗压、主动补位，能适应快速迭代的一线业务节奏。

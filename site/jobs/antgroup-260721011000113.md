## 岗位要求

专业能力
1. AI编程工具重度玩家：Cursor、Claude code等AI编程工具重度或顶级玩家，具备极强的Prompt编写与调优能力，有过完整的项目级开发经验，理解如何让AI写出生产级代码；
2. 大模型能力理解与掌握：理解主流LLM的能力与局限，能够清晰拆解任务并通过LLM或确定性逻辑兜底实现；熟悉主流大模型的应用范式(Context Engineering、Prompt Engineering、Agent、工具/函数调用等等)及主流Agent框架(如LangChain等)，具备大模型幻觉、Prompt注入等风险的工程化应对思路；
3. 扎实的代码和工程能力：能至少在一种主流编程语言（如 Java / Python / JS 等）上有深度的实践经验，能够根据场景灵活选型并快速上手。
能力特质
1. 开放性与动手能力：有自己独立完成的小项目（开源项目或个人 Demo），有技术极客精神；
2. 好奇心与想象力：面对未知事物有独特的想法，具备敏锐的问题定义能力和坚韧的解决问题能力；
3. 高能动性：具备强烈的自驱力，能够主动探索边界。
加分项（优先考虑）
1. 对金融市场、投资研究或量化策略有发自内心的兴趣，乐于主动追踪市场动态、政策变化、行业轮动与前沿学术成果，享受将金融洞察转化为AI落地的过程，有实际投资经验或研究者更佳；
2. 理解基本的金融概念与投研流程（如资产定价、行业分析、组合管理、风险因子等），能够快速学习并抽象金融业务逻辑，将其转化为可落地的Agent任务。

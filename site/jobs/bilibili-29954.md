## 岗位要求

工作职责:
【工作职责】
1. SNS 内容创意运营
协助 IP 选题策划、文案撰写、素材整理与平台发布；结合网络热点、动画 IP 人设产出短视频脚本、图文文案、互动话题、表情包等创意衍生内容，运用 AI 工具辅助素材创作与内容迭代。
2. 线下活动落地支持
配合商场巡展、动漫展会等线下活动的方案筹备与落地执行；负责活动物料整理、现场执行及传播素材采集与整理，活动结束后产出复盘资料，并提炼可用于 SNS 传播的图文、短视频素材。
3. 数据监测与内容优化
跟踪各 SNS 平台内容数据（阅读、互动、曝光等指标），整理数据反馈，协助复盘内容效果，持续优化选题方向、内容形式与传播策略。
工作要求:
【任职要求】
1. 本科及以上在读学生，优先网络与新媒体、数字媒体艺术、广播电视编导、广告学（新媒体 / 数字营销方向）；动画、数字媒体技术、市场营销等相关专业亦可。
2. 具备基础内容创作能力，可独立撰写图文 / 短视频文案，熟悉社交平台传播逻辑；喜爱动画、ACG、儿童 IP 内容，对用户喜好、网络热点具备敏感度。
3. 工具适配能力：愿意主动学习各类 AI 辅助创作工具（ChatGPT、Midjourney、AI 视频工具等）；掌握 Office 套件，会使用剪映、Canva、基础 PS 等图文剪辑工具者优先。
4. 加分经历：拥有小红书 / B 站 / 微博等 SNS 账号实操运营经验；商场展会、线下活动策划执行经验；动画、IP、ACG 领域相关创作履历。
5. 拥有较强执行力、责任心，善于沟通，能够配合团队协同推进项目，接受工作排期。
 
投递材料要求：简历附带一份作品集，可选提交：过往运营的 SNS 账号链接 / 内容案例，或是利用 AI 工具创作的 IP 相关内容样例（图文、脚本、视觉素材均可，形式不限）

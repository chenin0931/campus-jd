## 岗位要求

岗位职责：

任职要求：

招聘对象：本、硕、博。

毕业时间：2026 年 9 月至 2027 年 8 月期间毕业（中国大陆以毕业证为准，非中国大陆地区以教育部学位认证为准）且最高学历毕业后无全职工作经验的学生。




你将会负责：

1.协助构建全球业务需求预测模型，分析各区域及业务线的人员需求趋势；

2.参与智能排班体系优化，支持实时监控，识别潜在风险与改进机会；

3.在导师指导下参与系统工具开发和流程改进项目，将数据洞察转化为可落地的业务方案；

4.使用 Excel、SQL 或 Python 分析业务数据，开展 ROI 分析、成本测算及项目效果评估；

5.与产品、技术、运营及海外团队协作，明确项目目标、成功标准及风险应对；

6.在真实业务环境中积累分析、项目管理及运营经验，参与团队复盘和反馈，优化工作方法。




我们期望你：

1.理工科、商科、数据分析、统计或计算机相关专业优先；

2.具备流利的英语听说读写能力，能够在国际化环境中高效沟通；

3.数据敏感，逻辑清晰，热爱用分析解决问题；熟练使用 Excel，了解 SQL / Python / Tableau / Power BI 优先；

4.乐于跨团队、跨区域协作；积极主动，能在导师指导下独立完成任务；具备良好团队精神；

5.学习能力强，善于问题拆解；自我驱动力高，能在快节奏、多任务环境中高效工作；对业务成长、影响力及运营实践充满兴趣；

6.了解大模型及 AI 应用的基本能力，且有较强兴趣；有 Prompt、RAG、Agent、Workflow、AI Skill 等相关实践经验优先。

## 岗位要求

1. 本科及以上学历，数学、统计、计算机、工科、商科等相关专业背景更佳；
2. 聪明严谨、积极有韧性，乐于面对挑战、具备优秀的分析能力；
3. 具备充分的好奇心，有钻研的精神，喜欢从数据中发现问题、分析规律更佳；对商业运作模式和企业经营感兴趣；
4. 数据科学（DS方向）具备计算机背景或经济学和理工科双学位专业背景更佳；
5. 了解大语言模型的基本能力，对AI赋能商业分析有探索兴趣，有使用AI工具辅助数据分析或报告撰写的经验者优先。
具备以下经验者优先：
1. 有使用AI工具辅助商业研究的实践经验，如利用大模型进行行业报告生成、数据可视化、用户调研分析等；
2. 了解Text-to-SQL、自然语言数据分析等AI+数据分析前沿方向；
3. 了解主流 Agent 开发框架（如 LangChain、Dify 等），有将 Agent 应用于数据分析或商业研究场景的经验。
【岗位亮点】
1. 距离决策者最近的岗位，数据规律将有机会驱动业务核心决策；
2. 多元化的业务场景，丰富的商业视角和实战土壤；
3. 体系化的人才培养机制；
4. 大模型与商业分析深度融合，可参与构建AI增强的智能分析平台。

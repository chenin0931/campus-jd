## 岗位要求

<p>一、你将做什么</p><p>- 成为下一代 AI 网页生成模型的训练者。</p><p>- 准确说出网页好在哪、差在哪、为什么：并把这些判断转化为可复用的评价标准。</p><p>- 我们不要"我觉得这个好看"，要的是：能从代码逻辑、设计规范、交互原则三个层面拆解一个页面，告诉模型怎么改才对。</p><p><br></p><p>二、主要职责</p><p>- 对 AI 生成的网页做结构化审美评价（好在哪 / 差在哪 / 怎么改）；</p><p>- 参与建设网页美学评价框架，把"美"拆成可量化、可标注的维度：版式、字体、配色、留白、信息层级、动效、品牌调性、时代感、交互逻辑等</p><p>- 阅读 AI 生成的 HTML / CSS 代码，定位审美问题的代码根因（比如，行间距问题是 line-height 还是 letter-spacing）</p><p>- 参与 case 设计、judge prompt 迭代</p><p><br></p><p>三、任职要求</p><p>- CS / HCI / 交互设计 相关专业背景</p><p>- 能读懂 HTML / CSS / 基础 JS，能上手在浏览器里改样式并说清楚为什么</p><p>- 有网页设计或前端实现经验，有作品集（个人站、独立项目、课程作业、Awwwards / Behance 投稿、Hackathon 项目都可以）</p><p>- 能用语言精确描述网站审美问题：不是"好看"或"高级感"，而是"grid 系统失衡、行间距偏紧、视觉重量集中在右上"</p><p>- 知道 AI 做网页时的常见审美陷阱（默认 Bootstrap 感、emoji 滥用、动效堆砌、Stock 配图等）</p><p><br></p><p>四、加分：</p><p>- 用过 Cursor / Claude Code / Lovable / Bolt / v0 这类工具搭过审美在线的网页，并能讲清楚你做对了什么</p><p>- 有独立博客 / 长推 / 设计评论 / 课程项目文章</p><p>- 关注 AI design 圈，对当下"什么样的网页算好"有自己的判断</p><p><br></p><p>五、你能拿到什么 / 这份工作能带你去哪</p><p>- 简历定位：下一代 AI 模型的训练者</p><p>- 参与定义"AI 网页应该长什么样"——这是行业还没有的标准</p><p>- 跨学科团队协作：算法研究员 + 设计师 + 工程师</p><p>- 结业后可去的方向：AI Designer / AI Product Designer / Prompt Engineer / Eval Engineer，也有机会在moonshot转正；带走的能力栈是"能用 AI 做美的产物 + 能给模型讲清楚审美"，前沿，跨界创新</p><p><br></p><p>六、投递方式</p><p>具体要求见：https://o4fkkfp42cx32.ok.kimi.link</p><p>- 发至：zhanhaobing@moonshot.cn</p><p>- 标题：网页美学评论_姓名</p><p>附件请包含：</p><p>1. 个人简历（PDF）</p><p>2. 作品集：优先看你做的网站（个人站、课程项目、Vibe Coding 产物——可以打开玩的最好）；UI/UX 类作品请附设计稿，我们会重点看设计逻辑是否符合设计规范</p><p>3. 一段 200-500 字网页评论：任选一个你最近看到的网站（好或坏都行），讲清楚它的审美选择、代码层面可能的实现、以及如果是你会怎么改</p><p>4. 作业题结果</p>

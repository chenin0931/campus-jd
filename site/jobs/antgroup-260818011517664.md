## 岗位要求

我们希望你
我们不要求你在入职前已经掌握所有海外平台和增长方法。相比完整的运营经历，我们更关注你的 Agent 使用深度和英文内容能力，也关注你能否快速学习并按时完成任务。
1. 英文读写和沟通能力好，能够与海外用户沟通，并写出清楚、自然的英文内容。
2. 熟悉至少一个海外内容或社区平台，并有过内容策划、写作、发布或账号运营经历。
3. 经常使用 Agent 工具处理学习、创作、编程或其他实际任务，能够具体说明自己的使用场景和习惯。
4. 自驱、可靠，能够适应产品和任务优先级的变化，并按时完成任务。
5. 愿意关注用户反馈和内容数据，并根据实际结果调整后续内容。
加分项
1. 有个人自媒体账号，或者参与运营过品牌、公司、社团及项目账号，并能说明自己的具体职责和成果。
2. 熟悉两个及以上海外平台，或者有英文内容、北美用户及开发者社区运营经验。
3. 具备短视频拍摄剪辑、视觉设计、产品 Demo 或其他多媒体内容制作能力。
4. 接触过海外创作者合作、付费内容推广或广告素材测试。
你将获得
1. 参与一款 AI 创新硬件从原型验证到市场发布的关键阶段。
2. 接触海外用户研究、产品表达、内容运营、社区增长和 GTM 实践。
3. 了解产品、设计、研发和市场如何协作，以及用户反馈如何影响产品表达和迭代。
4. 在真实业务中负责相对完整的内容任务，积累从策划、制作、发布到数据复盘的经验。
申请方式
申请时，请附上以下材料中的至少一种：
1. 个人自媒体账号。
2. 参与运营过的品牌或项目账号。
3. 英文文章、社媒内容、短视频或脚本。
4. 其他能够体现内容策划和制作能力的作品。
如果作品来自团队项目，请简单说明项目背景、你的具体职责和取得的结果。没有个人自媒体账号不影响申请，我们更关注你实际负责过什么，以及你是否具备内容判断和执行能力。
请同时介绍两个你最近经常使用的 Agent 工具，以及你分别用它们完成什么任务。
实习要求
1. 实习地点：杭州，需要线下到岗。
2. 每周到岗：4 天及以上。
3. 实习周期：至少 3 个月，能够连续实习 6 个月者优先。

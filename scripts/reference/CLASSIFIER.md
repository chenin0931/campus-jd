# 岗位分类规则（唯一标准）

适用于所有公司、所有抓取器（含新接入的公司）。各脚本里的旧 classify / classifyMore 已经作废，以本文件为准。

## 1. 取标题头
1. 去掉所有 `【…】` 和 `[…]` 前缀或片段。
2. 按第一个 `-`、`－`、`—` 或 `–` 切开，只取前面那段作为「标题头」，并去掉首尾空格。

## 2. 排除（技术类）
标题头含以下任一词就排除：
`开发` `研发` `算法` `工程师` `测试` `研究`

其他岗位全部保留。`设计` 不再排除。

## 3. 分类（按优先级，命中第一个就停）
| 优先级 | 类别 | 标题头关键词 |
|---|---|---|
| 1 | AI产品 | 含 `产品`，且含 `AI` / `大模型` / `Agent` / `AIGC` / `智能` 之一（AI 和 Agent 不区分大小写） |
| 2 | 产品 | `产品` |
| 3 | 运营 | `运营` |
| 4 | 商务 | `商务` `BD` `商业化` `渠道` `合作` `招商` `采购` `供应链` `投资` `战略` |
| 5 | 市场 | `市场` `营销` `品牌` `公关` `PR` `广告` `媒介` `增长` |
| 6 | 销售 | `销售` `客户经理` `大客户` `售前` `售后` `客户成功` `KA` |
| 7 | 设计 | `设计` `视觉` `交互` `UI` `UX` `美术` `原画` `动画` `插画` |
| 8 | 职能 | `HR` `人力` `招聘` `HRBP` `财务` `会计` `审计` `税务` `法务` `律师` `合规` `风控` `行政` `秘书` `助理` `内控` `IT支持` |
| 9 | 其他 | 都没命中（如 管培生、策划、编辑、客服、分析师、翻译、校园大使） |

说明：
- 关键词在**标题头**里匹配。英文缩写（BD、PR、KA、UI、UX、HR）不区分大小写，按整词匹配，免得误中别的英文词。
- 「产品运营」按优先级会归到 **产品**。这和旧规则不同（旧规则把含运营的都算运营）。
- 管培生没有单独的类别：标题头里有业务词的，按业务词归类（如「运营管培生」归运营，「商务管培生」归商务），只有「管培生」三个字的归其他。
- job_type 不变：`校招` / `实习`。

## 4. 参考实现（JS）
```js
const EXCLUDE = /开发|研发|算法|工程师|测试|研究/;
const AI = /AI|大模型|Agent|AIGC|智能/i;
const RULES = [
  ['运营', /运营/],
  ['商务', /商务|(^|[^A-Za-z])BD([^A-Za-z]|$)|商业化|渠道|合作|招商|采购|供应链|投资|战略/i],
  ['市场', /市场|营销|品牌|公关|(^|[^A-Za-z])PR([^A-Za-z]|$)|广告|媒介|增长/i],
  ['销售', /销售|客户经理|大客户|售前|售后|客户成功|(^|[^A-Za-z])KA([^A-Za-z]|$)/i],
  ['设计', /设计|视觉|交互|(^|[^A-Za-z])(UI|UX)([^A-Za-z]|$)|美术|原画|动画|插画/i],
  ['职能', /(^|[^A-Za-z])HR(BP)?([^A-Za-z]|$)|人力|招聘|财务|会计|审计|税务|法务|律师|合规|风控|行政|秘书|助理|内控|IT支持/i],
];
function classify(title) {
  const h = String(title).replace(/【[^】]*】|\[[^\]]*\]/g, '').split(/\s*[-－—–]\s*/)[0].trim();
  if (EXCLUDE.test(h)) return null;
  if (h.includes('产品')) return AI.test(h) ? 'AI产品' : '产品';
  for (const [c, re] of RULES) if (re.test(h)) return c;
  return '其他';
}
```
